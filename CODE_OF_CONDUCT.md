# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, as its code of conduct. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we expect everyone participating in this project, in any space it uses,
to be respectful, welcoming, and harassment-free.

## Reporting

To report abusive, harassing, or otherwise unacceptable behavior, contact the
maintainers privately at **Koduhai@koduhai.com**. All reports are reviewed and
handled confidentially.
